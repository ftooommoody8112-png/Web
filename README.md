# Web# البوابة الرقمية للأعمال والإنجازات

بوابة رقمية تجمع أعمال ومشاريع الويب في مكان واحد، وتتيح استعراضها بطريقتين: معرض المشاريع والعرض التقديمي التفاعلي.

## الأقسام الرئيسية

1. المشاريع الرقمية: `index.html` — استعراض الموقع والخدمات الرقمية الفاخرة.
2. العرض التقديمي: عرض تفاعلي جاهز للعملاء والزوار.

## التشغيل محليًا

افتح ملف `index.html` الموجود في المجلد الرئيسي لاستعراض الموقع مباشرة.

## النشر على GitHub Pages

الموقع منشور حالياً بشكل تلقائي ومباشر عبر GitHub Pages وجاهز للاستعراض.
